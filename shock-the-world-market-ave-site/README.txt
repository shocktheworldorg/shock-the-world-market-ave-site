SHOCK THE WORLD - Market Ave Community Impact Campus
Website package
====================================================

WHATS INSIDE
  index.html   -> the website (open in any browser to preview)
  assets/      -> all images used by the site
  README.txt   -> this file

HOW TO PUBLISH (pick one)

  1) Netlify Drop (fastest, free)
     - Go to app.netlify.com/drop
     - Drag this WHOLE folder onto the page
     - You get a live link in seconds. Add your own domain later in Site settings.

  2) GitHub Pages
     - Create a repo, upload the contents of this folder (index.html at the root)
     - Settings -> Pages -> deploy from the main branch.

  3) Any web host / cPanel
     - Upload the contents of this folder to public_html (or the web root).
     - index.html must sit at the top level with the assets/ folder beside it.

  4) Wix
     - Wix does not import a full HTML site. Use index.html as your visual
       blueprint and rebuild it section-by-section in the Wix Editor, or embed
       index.html via Add -> Embed Code (works, but as one locked block).

NOTES
  - Keep index.html and assets/ together. Move one, move both.
  - To swap a photo: drop a new image into assets/ using the SAME filename.
